# Tech Stack

## Core
- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## 3D & Animation
- **3D:** @react-three/fiber, @react-three/drei
- **Animation:** GSAP, Framer Motion
