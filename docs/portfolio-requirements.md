# Portfolio Requirements

## Core Requirements
- [x] World-class, unique, professional 3D animated portfolio
- [x] Miximalist style: bold typography + generous whitespace + subtle 3D depth
- [x] Dark theme with electric blue accent (#2563EB)
- [x] World-class animated background (particles, gradient orbs, grid, noise)
- [x] Fully responsive: desktop, tablet, mobile optimized
- [x] Mouse parallax + scroll-driven animation
- [x] 3D floating particles/balls background
- [x] Animated avatar (photo provided by user)
- [x] Scroll-driven 3D scene
- [x] Custom cursor
- [x] Page transitions
- [x] Glassmorphism cards

## Sections
1. **Hero** — Name, title, animated intro, 3D avatar
2. **About** — Bio, skills overview
3. **Projects** — 6 featured projects with links
4. **Skills** — Tech stack showcase
5. **Contact** — Email, GitHub, LinkedIn, WhatsApp

## Technical
- Next.js with TypeScript
- React Three Fiber for 3D
- GSAP for animations
- Tailwind CSS for styling

## Commands
```bash
npm run dev   # Start dev server
npm run build # Build production
```
